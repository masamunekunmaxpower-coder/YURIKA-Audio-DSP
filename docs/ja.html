YURIKA
Audio DSP

YouTubeとブラウザ音声を、Chromeの中でリアルタイム処理。Self-DAP、HRTF、Spatial、ヘッドホン補正、C++/WASM仮想アンプまで積んだ、ちょっと盛りすぎな音響システムです。

何がそんなに変なのか

普通のEQ拡張ではありません。ブラウザ内の多段DSPとして、音質・空間・安全系・診断系を別モジュールで積み上げています。

🎧

Self-DAP / Headphone

自作DAP設計の考え方をソフトウェアへ写像し、ヘッドホン補正や高域補完と統合。

🧭

HRTF / Spatial

ITD/ILD/IACCなどの診断を持つ立体音響系。HRTFとの二重盛りを避ける設計。

⚙️

C++ / WebAssembly

Virtual Class-A段はC++→WASM→AudioWorklet。失敗時はunity bypassへ逃がします。

🧪

Diagnostics

Peak/RMS、相関、Spatial状態、Amp状態などをリアルタイム観測。

🛡️

Safety

LimiterとAdaptive Safetyで暴走を抑制。音が止まるより安全側へフォールバック。

▶️

YouTube

Chromeタブ音声を処理し、YouTube向けA/V同期補助も搭載。

導入

  1. GitHubからリポジトリをDownload ZIPまたはclone。
  2. Chromeで chrome://extensions を開く。
  3. デベロッパーモードをON。
  4. 「パッケージ化されていない拡張機能を読み込む」を押す。
  5. extension/ フォルダを選択。
  6. YouTube等でYURIKAを開き、DSPを有効化。

Chrome 116+想定。音声を外部サーバーへアップロードする経路は公開ソースには含まれていません。
