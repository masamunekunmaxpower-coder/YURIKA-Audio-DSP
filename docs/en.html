Unofficial derivative/fan-made project based on TRICKCAL: Mochimochi Cheeks Daisakusen. Not an official TRICKCAL / EPIDGames / BILIBILI release.

Why is this thing so extra?

It is not a basic EQ or volume booster. YURIKA is a modular browser audio pipeline that treats rendering, spatial cues, safety and diagnostics as separate stages.

🎧

Self-DAP / Headphones

Software mapping of a DIY-DAP design philosophy, combined with headphone correction and restoration controls.

🧭

HRTF / Spatial

Spatial processing with ITD/ILD/IACC diagnostics and cue-preservation logic instead of blindly stacking effects.

⚙️

C++ / WebAssembly

The Virtual Class-A stage runs C++ → WASM → AudioWorklet, with fail-open unity bypass if the module goes sideways.

🧪

Diagnostics

Live peak/RMS, stereo correlation, spatial state and amplifier runtime telemetry.

🛡️

Safety first

Limiter and adaptive trim keep the pipeline from doing something cursed when levels get spicy.

▶️

YouTube-ready

Processes captured Chrome-tab audio and includes YouTube A/V synchronization helpers.

Install from source

  1. Download the repository ZIP or clone it.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Choose Load unpacked.
  5. Select the extension/ directory.
  6. Open YouTube, launch YURIKA, enable processing, pick a preset.

Designed for Chrome 116+. The public source does not include an external audio-upload path. No cloud fairy dust required.
