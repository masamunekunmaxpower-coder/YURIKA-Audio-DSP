왜 이렇게까지 만들었냐고요?

그냥 EQ나 볼륨 부스터가 아닙니다. YURIKA는 음질, 공간 단서, 안전 처리, 진단을 단계별로 나눈 브라우저 오디오 파이프라인입니다.

🎧

Self-DAP / Headphone

DIY DAP 설계 철학을 소프트웨어로 옮기고, 헤드폰 보정과 고역 복원 제어를 결합했습니다.

🧭

HRTF / Spatial

ITD/ILD/IACC 진단과 cue 보존 로직을 갖춘 공간 음향 처리. 효과를 무작정 겹치지 않습니다.

⚙️

C++ / WebAssembly

Virtual Class-A는 C++ → WASM → AudioWorklet. 오류가 나면 소리를 끊기보다 unity bypass로 빠집니다.

🧪

Diagnostics

Peak/RMS, 스테레오 상관, 공간 상태, 앰프 런타임 상태를 실시간으로 봅니다.

🛡️

Safety

Limiter와 Adaptive trim으로 레벨이 과해질 때 제어합니다. 사고 나기 전에 말리는 쪽.

▶️

YouTube

Chrome 탭 오디오를 처리하고 YouTube A/V 동기화 보조도 포함합니다.

설치

  1. GitHub에서 ZIP을 받거나 clone합니다.
  2. Chrome에서 chrome://extensions 를 엽니다.
  3. 개발자 모드를 켭니다.
  4. 압축해제된 확장 프로그램을 로드합니다를 선택합니다.
  5. extension/ 폴더를 지정합니다.
  6. YouTube에서 YURIKA를 열고 DSP를 켠 뒤 preset을 선택합니다.

Chrome 116+ 기준. 공개 소스에는 오디오를 외부 서버로 업로드하는 경로가 들어 있지 않습니다.
