# YURIKA Audio DSP website setup

## GitHub Pages
1. Merge the contents of `docs/` into the repository `docs/` directory.
2. Commit and push to `main`.
3. GitHub → Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`; folder: `/docs`; Save.
6. Site URL: https://masamunekunmaxpower-coder.github.io/YURIKA-Audio-DSP/

`.nojekyll` is included so the static site is served without Jekyll processing.

## Social preview
Upload `docs/assets/social-preview.png` in repository Settings → Social preview. It is 1280×640 PNG and under 1 MB.

## Release
Create tag `v3.3.2` and a GitHub Release. The website buttons point to `https://github.com/masamunekunmaxpower-coder/YURIKA-Audio-DSP/releases/latest`.
